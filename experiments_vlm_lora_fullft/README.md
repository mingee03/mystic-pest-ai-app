## Ⅰ. 실험 배경: 대표님·교수님 5대 핵심 피드백 및 해결 설계

| 번호 | 대표님 · 교수님 핵심 피드백 | 본 심화 실험의 해결 및 검증 설계 |
| :-: | :--- | :--- |
| **1** | **VLM 학습·평가 데이터가 너무 적음 (100장 Toy Sample 한계)** | 전체 데이터셋을 **800장(`Train 600장 / Val 100장 / Test 100장`)으로 약 8~10배 대폭 확대**하고, 촬영 원본 `Group ID`를 100% 격리하여 데이터 누수(Leakage) 원천 차단 |

| **5** | **더 큰 데이터(Train 100장 vs 600장 / Test 100장)에서 학습 안정성 재검증** | 동일 `Rank 8` 기준 **소규모(100장 학습) vs 대규모(600장 학습)**의 Val Loss 수렴도 및 Test 100장 진단 정확도·환각률을 직접 대조하여 대규모 데이터의 필수성 입증 |

### 💡 핵심 분석 인사이트 (보고서 및 발표 핵심 근거)

1. **왜 100장 학습이 Toy Sample이었는가? (`Small 100장 vs Expanded 600장`)**
   * 동일한 `LoRA Rank 8`임에도 **100장만 학습했을 때(`LoRA Rank 8 Small`)는 대규모 Test 100장에서 정확도가 `78.0%`에 그치고 Val Loss가 `1.3376`에서 멈추며 거절(2건)과 반복 루프(3건)가 잔존**했습니다.
   * 반면 AI 생성 설명 데이터로 **600장(`LoRA Rank 8 Expanded`)을 학습시키자 Val Loss가 `1.3376 ➔ 0.0286`으로 97.9% 급감하고, 진단 정확도가 `78.0% ➔ 94.0% (+16.0%p)`로 도약**했습니다.
2. **데이터 확대 시 LoRA Rank 역전 현상 (`Rank 8 vs Rank 16`)**:
   * 기존 100장 소규모 데이터에서는 `Rank 16`이 파라미터 용량 과잉으로 과적합·어절 반복을 일으켰으나, **600장 대규모 데이터에서는 `Rank 16`이 풍부한 시각·농업 지식을 온전히 흡수하여 `Val Loss 0.0201`, `Test 100장 정확도 100.0%`, `3단계 포맷 준수율 87.0%`, `환각/루프 0.0%`로 전체 모델 중 최고 성능**을 달성했습니다.
   * 반면 `Rank 4`는 표현력(Capacity) 부족으로 해충 이름은 맞히더라도(`89.0%`) 3단계 상세 방제 포맷 준수율이 `49.0%`로 급락했습니다.
3. **LoRA vs Full Fine-tuning 실측 비교**:
   * 메모리 최적화(`Gradient Checkpointing + Adafactor`)를 통해 단일 RTX 3090(24GB)에서 22억 개(`2.2B`) 전체 파라미터를 학습하는 **Full Fine-Tuning 완주에 성공(`Peak VRAM 13,857 MB`)**했습니다.
   * Full Fine-Tuning 역시 Test 100장 정확도 `100.0%`, 환각 `0.0%`의 우수한 성능을 보였으나, **`LoRA Rank 16 (600장)`은 전체 파라미터의 단 `0.197%`(1/500 수준)만 학습하여 VRAM을 `35.4%` 절감(`13.8GB ➔ 8.9GB`)하고 학습 속도를 1.8배 단축하면서도, 포맷 준수율(`87.0% vs 81.0%`)과 Val Loss(`0.0201 vs 0.0771`)에서 오히려 Full Fine-Tuning을 앞서는 최고의 효율성**을 입증했습니다.

## Ⅲ. [피드백 4 실측] YOLO 바운딩 박스 가이딩 방식 및 왜곡 강건성(Robustness) 5종 실험

### 💡 바운딩 박스 강건성 실험 핵심 결론

1. **대표님 가설 100% 입증 — 숫자 좌표 텍스트(`[x, y, w, h]`)의 역효과 확인**:
   * 동일한 모델에 바운딩 박스를 시각적으로 그려주었을 때는 정확도가 **`94.0%`**, 포맷 준수율이 **`80.0%`**에 달했으나, **숫자 좌표(`[x=..., y=..., w=..., h=...]`)를 텍스트로 전달하자 정확도가 `91.0%`로 떨어지고 포맷 준수율도 `74.0%`로 하락**했습니다.
   * 즉, 2B 규모의 소형 VLM에게 부동소수점 좌표 숫자는 공간 정보로 해석되기보다 텍스트 토큰 노이즈로 작용함을 정량적으로 증명했습니다.
2. **YOLO 박스 위치 이동(+25%) 및 크기 절반 축소(50%)에 대한 탁월한 강건성(Robustness)**:
   * 바운딩 박스 위치가 인위적으로 25% 밀리거나(`96.0%`), 크기가 절반으로 줄어들어 해충의 일부만 포함하더라도(`94.0%`), VLM이 박스 주변의 시각적 맥락과 해충 형태를 종합적으로 참조하여 **정확도 저하 없이 94~96%의 안정적인 진단 성능을 유지**했습니다.
   * 반면 박스를 아예 제거(`No Visual BBox`)하면 해충 종류는 맞히더라도 구조화된 3단계 방제 보고서 포맷 준수율이 `80.0% ➔ 73.0% (-7.0%p)`로 하락하여, **시각적 바운딩 박스가 VLM의 주의 집중(Visual Attention)과 출력 구조 안정화에 핵심 앵커 역할**을 함을 확인했습니다.
